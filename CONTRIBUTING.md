# Contributing

This repository is primarily a portfolio engineering project. Contributions should preserve the documented security, privacy, safety, and migration invariants.

Before a material change:

1. Update requirements/ADR artifacts when architecture changes.
2. Add or update tests for business invariants.
3. Avoid hardcoded secrets.
4. Do not weaken authorization to simplify development.
5. Mark evidence honestly; do not claim tests/builds passed unless executed.
