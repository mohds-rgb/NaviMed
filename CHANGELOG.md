# Changelog

## 0.1.0 — Portfolio baseline

- Established MVP project control artifacts and requirement traceability.
- Selected Supabase Auth + PostgreSQL + FastAPI from owner decisions.
- Added appointment domain state machine, hold logic, idempotency and audit records.
- Added pharmacy duty verification/publication model and emergency contact administration boundary.
- Added provider-neutral messaging abstraction with disabled/demo adapters.
- Added Flutter mobile application foundation with Arabic/English direction handling and safe-read UX.
- Added CI templates, Docker Compose, security documentation and migration boundary.

No deployment or live integration is claimed.
