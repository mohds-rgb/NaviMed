# Security Policy

NaviMed handles potentially sensitive healthcare coordination data. This portfolio repository is not a production deployment and contains no production credentials.

## Scope

Relevant reports include authentication/authorization bypasses, cross-tenant access, appointment integrity failures, public-data leakage, secret leakage, unsafe update behavior, webhook spoofing, and sensitive-data logging.

## Do not submit

Do not include patient data, credentials, private keys, provider tokens, or production logs in an issue or pull request.

## Disclosure

For this portfolio project, report reproducible security issues privately to the repository owner at `moydous@gmail.com`. Do not include sensitive healthcare data in the report.
